# 2D CAD Application

This folder contains the built and deployable version of the 2D CAD application.

## GitHub Pages Configuration

To deploy this application:

1. Go to your repository Settings
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Choose "main" branch and "/docs" folder
5. Click "Save"

The application will be available at: `https://maneegit.github.io/2D-CAD/`

## Built with:
- Three.js for 3D graphics
- Two.js for 2D graphics
- Parcel for bundling
- Vanilla JavaScript

## Development
To rebuild this folder, run from the project root:
```bash
npm run build:docs
```
